# Agent Skills

## Короткий зміст
Agent Skill — каталог із файлом SKILL.md, де в YAML frontmatter задано name і description, а в тексті — інструкції для агента. Агент підключає навичку, коли її опис відповідає завданню.

## Основні твердження
- Workspace skill живе в проєкті (.agents/skills/) і діє лише там; глобальна навичка доступна в усіх проєктах користувача.
- Progressive disclosure: спершу агент бачить лише name і description, повний текст підвантажує за потреби, довідкові файли — ще пізніше.
- Правила навички варто формулювати як обмеження: не вигадувати джерела, не видаляти без підтвердження.
