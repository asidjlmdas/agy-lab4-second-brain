# Markdown та YAML frontmatter

## Короткий зміст
Markdown — легкий текстовий формат розмітки; YAML frontmatter на початку файлу зберігає метадані (title, tags, status тощо) у зручній для людини й програми формі.

## Основні твердження
- Файл .md відкривається будь-яким редактором і добре працює з Git.
- Frontmatter міститься між двома рядками «---» на початку файлу.
- Відкритий формат зменшує залежність від конкретного застосунку, див. [[Vendor lock-in]].
- Вікі-посилання `[[Назва]]` — домовленість застосунків для нотаток, а не частина базового Markdown.
