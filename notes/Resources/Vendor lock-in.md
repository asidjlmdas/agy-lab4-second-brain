# Vendor lock-in

## Короткий зміст
Vendor lock-in — залежність від одного постачальника, коли перехід до іншого надто дорогий або неможливий через закриті формати, власні API чи особливості платформи.

## Основні твердження
- Джерела залежності: власні API, закриті формати даних, специфічні керовані сервіси, вартість виходу.
- Зменшення ризику: відкриті формати (Markdown), стандартні протоколи, контейнери, регулярний експорт даних.
- Локальні файли + Git практично не мають lock-in, але потребують власного резервування, див. [[Резервне копіювання 3-2-1]].
