# Метод PARA

## Короткий зміст
PARA ділить усі матеріали на чотири класи: Projects, Areas, Resources, Archives. Додатковий каталог Inbox тимчасово зберігає нові нотатки до розбору.

## Основні твердження
- Projects — активні результати з дедлайном (наприклад, здати лабораторну).
- Areas — довготривалі сфери відповідальності без кінцевої дати (навчання, здоров’я).
- Resources — тематичні матеріали для довідки.
- Archives — завершене або неактивне; нічого не видаляється, а переноситься.
- Inbox відокремлює сирі записи від перевіреної бази знань.
