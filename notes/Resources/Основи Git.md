# Основи Git

## Короткий зміст
Git — розподілена система керування версіями. Зміни проходять шлях: робочий каталог → індекс (git add) → коміт (git commit) → віддалений репозиторій (git push).

## Основні твердження
- Коміт має хеш, автора, дату й повідомлення; повідомлення повинно пояснювати зміст змін.
- Гілка — рухомий вказівник на коміт, HEAD показує поточну позицію.
- Основні команди: init, clone, status, add, commit, log, branch, switch, push, pull.
- Секрети й персональні дані не комітять; для цього існує .gitignore.
- Git — не резервна копія, див. [[Резервне копіювання 3-2-1]].
