# Права доступу в Linux

## Короткий зміст
Кожен файл має власника, групу та права r (читання), w (запис), x (виконання) для власника, групи й решти. Числовий запис: r=4, w=2, x=1.

## Основні твердження
- Спільний каталог для групи: власник root, група developers, права 2770.
- Біт setgid (2) на каталозі змушує нові файли успадковувати групу каталогу.
- Sticky bit (1), як у /tmp, дозволяє видаляти файли лише їхньому власнику.
- Користувача створюють командою useradd, до додаткової групи додають через usermod -aG.
- Принцип мінімальних привілеїв застосовується і до AI-агентів, див. [[Приватність і AI-сервіси]].
