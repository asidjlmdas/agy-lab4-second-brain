# Резервне копіювання 3-2-1

## Короткий зміст
Правило 3-2-1: щонайменше три копії даних, на двох різних типах носіїв, і одна копія в іншому місці (поза основною локацією).

## Основні твердження
- Git зберігає історію змін, але не замінює резервну копію: видалений віддалений репозиторій чи втрата облікового запису забирає все.
- До коміту потрапляють лише відстежувані файли; незакомічені зміни й ігноровані файли не збережені.
- Резервну копію варто періодично перевіряти відновленням.
- Приклад для Second Brain: робочий каталог, зовнішній диск і віддалений репозиторій; див. [[Основи Git]].
